# POSTITON OL 需求文档

## 1. 项目背景

原始应用为 Python Tkinter 桌面端文件 `position_manager_app.py`，主要用于个人交易操作分析，核心理念为：

- 以损定量
- 强制风控
- 持仓状态监控
- 预仓位与破位预警

本次目标是将其整理为独立线上网页端项目，便于部署到 Vercel，并适配 iPhone 15 屏幕。

## 2. 目标范围

### 必须实现

- 独立项目目录：`POSTITON_OL`
- Web 端运行
- 提供一个真实的 HTML 主页文件
- Vercel 可部署
- iPhone 15 屏幕适配
- 保留原 Python 版本核心计算逻辑
- 数据可保存、导出、导入、重置
- 需求文档与代码放在同一项目目录中

### 暂不实现

- 登录系统
- 云端数据库
- 多设备自动同步
- 股票实时行情接口
- 多用户权限管理

## 3. 页面结构

### 3.1 全局战略看板

字段：

- 总资产
- 成本本金
- 目标盈利
- 当前盈利
- 目标达成率

计算规则：

```text
目标达成率 = 当前盈利 / 目标盈利 * 100
```

当目标盈利为空或为 0 时，目标达成率显示 `0.00%`。

### 3.2 持仓状态雷达

每个持仓以卡片方式展示，适配手机单列布局。

手动输入字段：

- 代码
- 仓位
- 预仓位
- 现价
- 成本
- 止损额

自动计算字段：

- 持仓总额
- 预仓转换成本价
- 盈亏
- 恢复涨幅
- 止损价
- 离场空间
- 预警状态

计算规则：

```text
持仓总额 = 现价 * 仓位
```

```text
若 仓位 >= 预仓位：
  预仓转换成本价 = 持仓总额 / 预仓位
否则：
  预仓转换成本价 = 成本
```

```text
盈亏 = (现价 - 成本) * 仓位
```

```text
恢复涨幅% = (预仓转换成本价 - 现价) / 现价 * 100
```

```text
止损价 = 成本 - 止损额 / 仓位
```

```text
离场空间% = (现价 - 止损价) / 现价 * 100
```

预警规则：

```text
若 离场空间% < 2：
  预警 = 破位预警
否则若 仓位 / 预仓位 > 1：
  预警 = 超预仓
否则：
  预警 = 正常
```

### 3.3 以损定量执行区

每张持仓卡片内保留执行区。

输入字段：

- 买入价
- 日内仓位
- 止损额

自动计算：

```text
执行止损价 = 买入价 - 止损额 / 日内仓位
```

若执行字段为空，则优先使用该持仓卡片中的成本、仓位、止损额作为占位参考。

## 4. 移动端适配

目标设备：iPhone 15。

设计要求：

- 最大页面宽度控制在 430px
- 单列卡片布局
- 底部固定操作栏
- 适配 iOS 安全区
- 表单控件适合手指点击
- 深色 iOS 风格
- 风险状态颜色突出

## 5. 数据存储

当前版本使用浏览器本地存储：

```text
localStorage key = postiton_ol_state_v1
```

提供 JSON 导入/导出能力，方便备份和迁移。

## 6. 部署要求

平台：Vercel。

构建命令：

```text
npm run build
```

开发命令：

```text
npm run dev
```

运行环境：

- Node.js 18 或以上
- npm

## 7. HTML 主页

项目需要保留真实 HTML 主页文件，便于用户直接打开或作为静态入口查看。

文件位置：

```text
index.html
```

该文件为独立静态版本，不依赖 Next.js，包含：

- 全局战略看板
- 持仓状态雷达
- 以损定量执行区
- 本地保存
- JSON 导入/导出
- 重置

Next.js 的静态入口页：

```text
public/index.html
```
