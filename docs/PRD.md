## 1. 产品概述

### 1.1 背景

POSTITON OL 是由桌面端交易分析工具演化而来的**纯前端**网页应用。交易员在单一页面内录入持仓与资金参数，系统自动计算市值、盈亏、风控指标及加仓相关价位，用于盘中决策与复盘。

### 1.2 产品目标

- 提供「资金安全视图」：总市值、本金、欠款、盈利与目标达成率一目了然。
- 提供「持仓监控表」：多标的横向对比，支持快速编辑与风险状态标识。
- 提供「加仓执行区」：按固定公式生成止损价位与盈利回退止盈价。
- 数据仅存于浏览器本地，支持保存、导出、导入、重置。

### 1.3 非目标（本期不做）

- 用户登录与多设备云同步
- 行情 API 自动刷新现价
- 多用户权限与审计日志

## 3. 用户与使用流程

### 3.1 典型流程

1. 打开 `index.html`（或 Vercel 部署地址）。
2. 在全局区填写**本金**、**欠款**、**目标盈利**。
3. 在持仓表中为每只股票填写代码、名称、现价、成本、预计持仓、持仓数量等。
4. 查看自动计算的**市值**、**浮动盈亏**、**状态**；必要时展开「风控」或「加仓」。
5. 点击底部**保存**，或**导出 JSON** 备份。
6. 换设备时通过**导入**恢复数据。

### 3.2 核心操作

| 操作 | 触发方式 | 说明 |
| --- | --- | --- |
| 新增持仓 | 「+ 新交易」 | 新增一行，默认展开风控与加仓区 |
| 编辑字段 | 表格内输入 / 展开区输入 | 失焦后重算并刷新全局总市值 |
| 展开风控 | 「展开风控」 | 显示计划止损额、雷达指标 |
| 展开加仓 | 「加仓」 | 显示加仓执行区 |
| 删除持仓 | 「删除」 | 二次确认后移除行 |
| 保存 | 底部「保存」 | 写入 `localStorage` |
| 导出 / 导入 | 底部按钮 | JSON 文件 |
| 重置 | 底部「重置」 | 清空并恢复 4 条空行 |

## 4. 功能模块详述

### 4.1 全局风险脉冲

**展示条件**：任意持仓行的「离场空间」&lt; 2%（状态为「异常」）。

**表现**：

- 顶栏下方红色提示条显示：「风险脉冲：有持仓逼近或跌破止损线，请立即处理。」
- 支持设备振动（`navigator.vibrate`，若可用）。

---

### 4.2 GLOBAL HEADER — 资金安全视图

#### 4.2.1 字段说明

| 字段 | 类型 | 可编辑 | 说明 |
| --- | --- | --- | --- |
| 总市值 | 数字 | 否（只读） | 所有持仓「市值」之和 |
| 本金 | 数字 | 是 | 投入资金 |
| 欠款 | 数字 | 是 | 负债金额 |
| 目标盈利 | 数字 | 是 | 盈利目标 |
| 当前盈利 | 数字 | 否（只读） | 由总市值、本金、欠款推导 |
| 目标达成率 | 百分比 | 否 | 环形进度 + 文案，上限 100% 用于环显示 |
| 最近保存 | 文本 | 否 | 点击「保存」时写入的时间 |

#### 4.2.2 计算公式

```text
单行市值 = 成本 × 持仓数量
（成本或持仓数量缺失时，该行市值不计入合计）

总市值 = Σ 各行市值

当前盈利 = 总市值 - 本金 - 欠款
（本金、欠款为空时按 0 处理）

目标达成率 = 当前盈利 / 目标盈利 × 100%
（目标盈利为空或为 0 时，显示 0.00%）
```

#### 4.2.3 交互

- 修改本金、欠款、目标盈利时实时重算当前盈利与达成率。
- 修改任意持仓的成本或持仓数量时，总市值联动更新，进而更新当前盈利与达成率。

### 4.3 POSITION MONITOR — 持仓监控表

#### 4.3.1 主表列（从左到右）

| 列名 | 类型 | 可编辑 | 说明 |
| --- | --- | --- | --- |
| 股票名称 | 代码 + 名称 | 是 | 含操作按钮：加仓 / 风控 / 删 |
| 市值 | 只读 | 否 | 成本 × 持仓数量 |
| 现价 | 数字 | 是 | |
| 成本 | 数字 | 是 | |
| 预计持仓 | 数字 | 是 | 预仓数量 |
| 持仓数量 | 数字 | 是 | |
| 浮动盈亏 | 只读 | 否 | (现价 - 成本) × 持仓数量 |
| 状态 | 只读 | 否 | 正常 / 超预仓 / 异常 |

**行内操作**：

- **加仓 / 收起**：展开/收起加仓执行区
- **风控 / 收起**：展开/收起持仓状态雷达
- **删**：删除当前行

**颜色规则（浮动盈亏）**：

- 盈利 &gt; 0：红色（`red`）
- 亏损 &lt; 0：绿色（`green`）

#### 4.3.2 持仓状态雷达（风控展开区）

**可编辑字段**（与主表部分重复，便于集中编辑）：

- 持仓数量、预仓数量、现价、成本、当日盈亏、计划止损额

**自动指标**：

| 指标 | 公式 | 备注 |
| --- | --- | --- |
| 预仓转换成本价 | 若 持仓数量 ≥ 预仓数量：现价×持仓数量÷预仓数量；否则：成本 | 预仓为 0 时不计算 |
| 恢复涨幅 | (成本 - 现价) / 现价 × 100% | 仅当现价 &lt; 成本时计算 |
| 止损价 | 成本 - 计划止损额 / 持仓数量 | 持仓数量为 0 时不计算；若存在历史字段 `execStopPrice` 则优先使用 |
| 离场空间 | (现价 - 止损价) / 现价 × 100% | |

**状态判定**：

```text
若 离场空间 < 2%：
  状态 = 异常（红色脉冲）
否则若 持仓数量 / 预仓数量 > 1：
  状态 = 超预仓（琥珀色）
否则：
  状态 = 正常（绿色）
```

#### 4.3.3 加仓执行区

**模块标题**：加仓执行区  
**副文案**：输入加仓参数，自动生成止损价位和盈利回退止盈价

**输入字段**：

| 字段 | 字段键 | 说明 |
| --- | --- | --- |
| 加仓数 | `addCount` | 本次加仓股数，不可为 0 |
| 加仓位 | `addPrice` | 加仓成交价格 |
| 止损额 | `addStopAmount` | 允许亏损金额；占位默认取「计划止损额」 |
| 高点位 | `addHighPrice` | 加仓后参考高点 |

**输出字段（只读）**：

| 字段 | 公式 |
| --- | --- |
| 止损价位 | (加仓数 × 加仓位 - 止损额) / 加仓数 |
| 盈利回退止盈价 | (高点位 - 加仓位) × 0.66 + 加仓位 |

**状态芯片**：

| 条件 | 文案 | 样式 |
| --- | --- | --- |
| 加仓数 = 0 | 加仓数无效 | 错误 |
| 止损价位或盈利回退止盈价无法计算 | 待输入 | 默认 |
| 两项均已生成 | 已生成 | 成功 |

**说明**：界面第三格展示「回退 66%」，对应盈利回退止盈价公式中的系数 0.66。

## 5. 数据模型

### 5.1 全局头 `globalHeader`

```json
{
  "totalAssets": "string",
  "costCapital": "string",
  "debtAmount": "string",
  "targetProfit": "string",
  "currentProfit": "string"
}
```

> `totalAssets`、`currentProfit` 由系统计算后写入状态，保存时一并持久化。

### 5.2 持仓行 `rows[]`

```json
{
  "id": "string",
  "symbol": "string",
  "name": "string",
  "position": "string",
  "plannedPosition": "string",
  "currentPrice": "string",
  "costPrice": "string",
  "dayPnl": "string",
  "stopLossAmount": "string",
  "addCount": "string",
  "addPrice": "string",
  "addStopAmount": "string",
  "addHighPrice": "string",
  "execBuyPrice": "string",
  "execDayPosition": "string",
  "execStopAmount": "string",
  "execStopPrice": "string",
  "rrRatio": "string"
}
```

后四个 `exec*` 与 `rrRatio` 为历史字段，界面已不再展示，导入旧数据时仍保留，不影响加仓模块。

### 5.3 根状态

```json
{
  "globalHeader": { },
  "rows": [ ],
  "updatedAt": "string | --"
}
```

### 5.4 本地存储

| 项 | 值 |
| --- | --- |
| Key | `postiton_ol_html_state_v1` |
| 介质 | `localStorage` |
| 导出文件名 | `postiton-ol-data.json` |

**初始化**：无缓存时默认 4 条空持仓行。

## 6. 交互与体验要求

### 6.1 布局

- 页面最大宽度 **430px**（iPhone 15 逻辑宽度），整体居中。
- **持仓监控表**采用紧凑标准：8 列按比例分配宽度，**无横向滚动**，一屏内展示全部列。
- 表头与数据字号约为常规版的 **1/3**（表头 8px、数据 7px、代码 9px），行高约 34px。
- 列宽比例：`1.55 : 0.82 : 0.72 : 0.72 : 0.88 : 0.82 : 0.9 : 0.68`（对应 8 列）。
- 底部四按钮固定于视口底部，最大宽度与页面一致，适配 `safe-area-inset`。

### 6.2 视觉

- 深色主题（iOS 风格）：紫青渐变背景、卡片半透明、等宽数字字体。
- 风险：红色脉冲动画；超预仓：琥珀色；正常：绿色。

### 6.3 输入

- 数字字段使用 `type="number"`、`inputmode="decimal"`。
- 编辑中若光标位于全局可编辑字段，渲染时不覆盖该输入框内容，避免打断输入。

### 6.4 空值与异常

- 无法计算时显示 `--`。
- 除法依赖项为 0 或缺失时，对应结果为 `null` → 显示 `--`。
- 无效数字（非有限数）按空值处理。

## 8. 验收标准

### 8.1 全局

- [ ] 总市值等于所有有效行「成本×持仓数量」之和。
- [ ] 当前盈利 = 总市值 - 本金 - 欠款。
- [ ] 目标达成率随目标盈利、当前盈利正确变化。
- [ ] 总市值、当前盈利不可手动编辑。

### 8.2 持仓表

- [ ] 主表 8 列显示正确，市值列在股票名称后。
- [ ] 浮动盈亏与状态规则符合公式。
- [ ] 离场空间 &lt; 2% 时出现顶栏风险脉冲。

### 8.3 加仓

- [ ] 输入加仓数、加仓位、止损额、高点位后，止损价位与盈利回退止盈价按 PRD 公式实时更新。
- [ ] 加仓数为 0 时状态为「加仓数无效」。

### 8.4 数据

- [ ] 保存后刷新页面数据仍在。
- [ ] 导出 JSON 再导入可完整恢复。
- [ ] 重置后恢复 4 条空行且全局字段清空。
